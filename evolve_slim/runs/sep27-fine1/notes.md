# sep27-fine1 notes

Keep rule used here: program.md's rule (regret down >= 0.0002 with time up <= 10%, or time down >= 10% with regret
up <= 0.0002), extended for this track's brief (a clearly lower training loss): a change that lowers mean_regret by
>= 0.0002 is also kept when geo_mean_time stays below 1.0 s (well under FasterRisk's 2.16 s). Test AUC is reported
for every attempt; drops are flagged.

Helpers: `dev.py` (fit chosen problems, regret e-4 / time / test AUC per solver file), `dbg*.py`, `prof.py`,
`tools.py` (set status, per-problem diff between two models).
